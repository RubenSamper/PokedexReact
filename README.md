Pokedex React

Aplicación web desarrollada con React que muestra una Pokédex completa utilizando la PokéAPI. Incluye listado de Pokémon, buscador, vista detallada, sistema de tipos y diseño responsive.
Características

    Interfaz desarrollada con componentes modulares de React.

    Consumo de la PokéAPI para obtener datos en tiempo real.

    Buscador de Pokémon por nombre o ID.

    Tarjetas con imagen, tipos y datos básicos.

    Vista detallada con estadísticas, altura, peso y más.

    Diseño responsive adaptable a móvil, tablet y escritorio.

    Despliegue mediante GitHub Pages.
