# Pokédex

Pokédex interactiva con información detallada de Pokémon, comparador, creador de equipos y más.

## 🚀 Desarrollo local

```bash
cd pokedex
npm install
npm run dev
```

## 📦 Despliegue

La app se despliega automáticamente en **GitHub Pages** al hacer push a `main`.

Solo haz push desde GitHub Desktop y el workflow de Actions lo publica solo.
